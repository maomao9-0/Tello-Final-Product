# Tello-Final-Product

A hackathon project that uses the Tello drone to to support public health efforts during pandemic scenarios. The system uses real-time computer vision to monitor indoor spaces and assist with social distancing. 

Demonstration video: https://www.youtube.com/watch?v=AQWsj5FPfq8

## Objective

1. Automatically identify individuals who require assistance by detecting raised-hand gestures.
2. Monitor distance between patients and alert them when social distancing guidelines are violated.

## Methodology

Used YOLO for real-time person detection, and trained custom hand-raise gesture recognition model using Teachable Machine.
